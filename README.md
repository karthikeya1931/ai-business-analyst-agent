# AI Business Analyst Agent

An agentic AI system that answers business questions using
SQL Server and Gemini.

## V1

- Natural-language business questions
- Gemini-powered SQL generation
- SQL Server execution
- Read-only SQL validation
- SQL error recovery
- Evidence-based final answers
- Agent step and SQL attempt limits

## Architecture

User
→ Gemini
→ Python agent
→ SQL Server
→ Gemini
→ Final answer

## Tech Stack

- Python
- Gemini API
- SQL Server
- SQLAlchemy
- Pandas
- PyODBC
